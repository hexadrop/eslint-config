# Development and testing

## Working on `packages/eslint-config-astro`

When rules, plugins, or config names change:

1. Update `packages/eslint-config-astro/src/astro.config.ts`.
2. Regenerate types with `bun run --filter @hexadrop/eslint-config-astro build:types`.
3. Rebuild the package with `bun run --filter @hexadrop/eslint-config-astro build` — the meta-package composes its `dist/`, so a stale build breaks root tests.
4. Run `bun run lint:fix` and `bun run typecheck` from the root.

## Tests

The suite is split by scope:

- `test/` — **unit tests**: the `astroFactory()` factory contract (config names, plugin registration, globs, rule states) and typescript auto-detection behavior covering both present and absent matrices.
- `e2e/` — **end-to-end tests**: a real ESLint `Linter` resolving the composed configs against source strings, pinning what a user actually sees.

## Typegen

`scripts/typegen.ts` writes `src/typegen.d.ts` (git-ignored, regenerated by the `prepare` script on install). Never commit the generated file.
